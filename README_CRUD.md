# 📋 PostHub - Complete CRUD Solution

## ✅ Что было исправлено

### Основные проблемы и решения:

1. **Проблема**: Посты исчезали при переходе на них
   - **Причина**: Приложение использовало JSONPlaceholder (mock API), который не сохраняет данные реально
   - **Решение**: Создан собственный Express.js бэкенд с реальным хранилищем данных

2. **Проблема**: Удалённые посты возвращались при обновлении страницы
   - **Решение**: Данные теперь сохраняются на сервере и синхронизируются правильно

3. **Проблема**: Изменения постов не сохранялись
   - **Решение**: Добавлена функция обновления (PUT) с проверкой авторства

4. **Требование**: Нужна была регистрация
   - **Решение**: Реализована полная система аутентификации с JWT токенами

### Бэкенд (Express.js)
✅ **Структура**:
```
server/
├── index.js              # Главный файл приложения
├── package.json
├── db.js                 # In-memory база данных
├── middleware/
│   ├── auth.js          # JWT аутентификация
│   └── errorHandler.js  # Обработка ошибок
└── routes/
    ├── auth.js          # Регистрация и логин
    ├── posts.js         # CRUD для постов
    └── users.js         # Получение информации о пользователях
```

**API Endpoints**:
```
AUTH:
- POST   /api/auth/register         # Создать аккаунт
- POST   /api/auth/login            # Вход

POSTS (требуется токен):
- GET    /api/posts                 # Получить все посты
- GET    /api/posts/:id             # Получить пост по ID
- GET    /api/posts/user/:userId    # Получить посты пользователя
- POST   /api/posts                 # Создать пост
- PUT    /api/posts/:id             # Обновить пост
- DELETE /api/posts/:id             # Удалить пост

USERS (требуется токен):
- GET    /api/users                 # Получить всех пользователей
- GET    /api/users/:id             # Получить пользователя по ID
```

## 📚 Использованные технологии

**Фронтенд**:
- React 18
- Redux Toolkit (управление состоянием)
- React Router (маршрутизация)
- Vite (сборка)

**Бэкенд**:
- Express.js (веб-фреймворк)
- JWT (аутентификация)
- bcryptjs (хеширование пароля)
- In-memory хранилище (временно, можно заменить на БД)

---

## 🔐 Безопасность

- Пароли хешируются с помощью bcryptjs
- JWT токены имеют срок действия 7 дней
- Защита маршрутов через middleware аутентификации
- Проверка авторства при редактировании/удалении постов

---

## 💾 Сохранение данных

На данный момент используется **in-memory хранилище**. Для продакшена рекомендуется:
- Заменить на MongoDB, PostgreSQL или другую БД
- Добавить переменные окружения (.env)
- Добавить валидацию на бэкенде
- Добавить логирование

## 🎯 Примеры использования

### Регистрация:
1. Перейти на http://localhost:5173/register
2. Заполнить форму (username, email, name, password)
3. Нажать "Register"
4. Будет создан аккаунт и автоматический вход

### Создание поста:
1. Перейти в раздел "Posts"
2. Нажать на кнопку создания поста
3. Заполнить title и body
4. Пост сохранится навсегда на сервере

### Редактирование поста:
1. Нажать на пост
2. Нажать "Edit"
3. Изменить данные
4. Нажать "Save Changes"

### Удаление поста:
1. Нажать на пост
2. Нажать "Delete"
3. Подтвердить удаление
4. Пост удалён **навсегда**

## 🆘 Если что-то не работает

1. Проверьте, что оба сервера запущены (порты 5000 и 5173)
2. Откройте DevTools (F12) и проверьте Network вкладку
3. Убедитесь, что token сохранён в localStorage
4. Проверьте консоль сервера на ошибки
